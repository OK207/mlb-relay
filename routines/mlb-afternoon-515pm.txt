AFTERNOON SESSION - 5:15 PM ET (line check for every sport + MLB evening games)

This session does two things, in this order:
A. RESULTS AND LINE CHECK, all year: settle anything that has gone final, and
   for every pick made today in any sport (and any open UFC pick) see whether
   the market has since moved toward it or away.
B. MLB EVENING GAMES, in season only: look once more at MLB games the morning
   card did not bet, now that lineups are posted.

Do not load the mlb skill or any other betting skill. All arithmetic, prices,
stakes, dates, file names and the Telegram send are done by scripts in
/home/user/mlb-relay/scripts. Never compute an edge, a payout or a stake
yourself, never type a date into a file name, and never write a picks, grades
or messages file by hand. If a script prints an error, report that error in
the text; do not work around it with numbers of your own.

======================================================================
STEP 0 - SYNC
======================================================================
cd /home/user/mlb-relay && git checkout -q main && git fetch -q origin main && git reset -q --hard origin/main

======================================================================
STEP A - RESULTS AND LINE CHECK
======================================================================
python3 scripts/grade.py all
python3 scripts/clv.py

The first command settles anything in any sport that has gone final since
the morning routines ran (a UFC card from the weekend, a late game). The
morning routines normally report results themselves, so do not put results
in this text; grading here only keeps the record and the sheet current.

The second, for each open pick, fetches the current prices and prints how the market's
fair probability has moved since the pick was made, or NO_OPEN_PICKS. Keep
the block it prints for the text. This is the number that says whether the
picks are finding anything: picks the market later moves toward have real
information behind them; picks it moves away from did not. Do not act on it
today - it is a measurement, not a signal to add or hedge.

======================================================================
STEP B - MLB EVENING GAMES (skip entirely when there is no MLB today)
======================================================================
D=$(TZ=America/New_York date +%F)
python3 scripts/fetch_daily_data.py --date $D --out-dir /tmp/mlb --no-odds && python3 scripts/game_sheet.py /tmp/mlb/$D.json

If that prints EMPTY SLATE there is no MLB today (off day or off-season): do
not run the next command, it would spend an odds credit on nothing.

python3 scripts/sheet.py mlb
cat picks/$(TZ=America/New_York date +%F).json 2>/dev/null || echo NO_MORNING_PICKS

On EMPTY SLATE, "NO GAMES WITH PRICES", every game being type S (Spring
Training), or prices being unavailable: there is nothing to do in STEP B.
Go to STEP C.

The prices sheet lists only games that have not started. Leave out any game
the morning card already bet (card.py refuses a second bet on a game anyway).
For the rest, the method is the morning card's, with one advantage: lineups
and late scratches are now known.

Only favorites priced from -105 to -200 can be bet, with both starters
confirmed. Work on at most three sides, those with the highest "edge before
any shift". Use up to 5 web searches for today's news only: WebSearch "<team>
lineup tonight scratches".

Decide a SHIFT for the favorite: how many points of win probability the fair
line should move toward it. Allowed reasons and their sizes:
- The opponent's announced starter scratched or replaced by an opener or
  bulk reliever after the current prices were set: +2 to +3.
- One or more of the opponent's best hitters out of the posted lineup, or the
  favorite gets a key bat back: +1 to +2.
- The opponent's high-leverage relievers pitched back-to-back days or threw
  25+ pitches yesterday while the favorite's are rested: +1 to +2.
- The opposing starter's last three starts clearly worse than his season
  line, or his ERA a run or more below his xERA: +1 to +2.
- Lineup OPS against this starter's hand .750+ for the favorite and under
  .680 for the opponent: +1.
- Combined, never more than +5.
Not reasons: records, streaks, momentum, the umpire, the park, or a good
starter simply being good. Pass when a starter is TBA, it is a bullpen game
for your side, or rain is above 40% at first pitch.

cat > /tmp/mlb_card.json <<'EOF'
{"picks": [
  {"id": "<id from the prices sheet>", "market": "ML", "side": "home", "shift": 3.0,
   "why": "<1-2 sentences: both starters by name, then the specific reason>"}
]}
EOF
python3 scripts/card.py mlb /tmp/mlb_card.json

Copy id and side exactly from the prices sheet. With nothing to bet, skip the
command. card.py adds any accepted pick to today's picks file alongside the
morning card, inside the same daily caps (4 bets, 5u), and prints the pick
lines. A REJECTED line is final.

Strikeout props are not part of this session any more: in six months the old
version never published one, and the scripts cannot price them.

STEP C - SEND, OR STAY SILENT
======================================================================
If STEP A printed NO_OPEN_PICKS and STEP B produced no pick (or did not run):

python3 scripts/publish.py mlb --record-only

Otherwise write the text. Plain ASCII, no emoji, no markdown:

Afternoon - <Mon D>

<the line-check block from STEP A, if any>

<the lines card.py printed, unchanged>

Leave out the MLB EVENING section when STEP B added no pick. Then:

cat > /tmp/pm_msg.txt <<'EOF'
<the text>
EOF
python3 scripts/publish.py mlb /tmp/pm_msg.txt --tag=-afternoon --no-record-line

publish.py saves the text, sends it to Telegram, falls back to the GitHub
relay if the direct send fails, and commits and pushes everything. It prints
SENT or SEND_VIA_RELAY, then PUSHED with the branch. In your final response
give those lines verbatim, what was sent (or "nothing to send"), and any
script error exactly as printed.
