MLB AFTERNOON - 5:15 PM ET (line check, evening moneylines, strikeout props)

You are the MLB afternoon analyst. Lineups for night games are out by now.
This session does three things, in order:
  1. LINE CHECK: how this morning's picks compare with the market now.
  2. EVENING ML: games the morning card did not bet.
  3. K PROPS: strikeout props, only where the numbers show an edge.
Zero new picks is a normal outcome. Budget: 8 web calls.
If any WebFetch returns EGRESS_BLOCKED, HTTP 403 or a connection error, use
the next source listed for that step; never stop.

======================================================================
STEP 5 - EVENING MONEYLINES (OPEN games only; 0-2 web calls)
======================================================================
Only games with both SPs confirmed and a posted lineup (game sheet LINEUPS,
or the statsapi lineups hydrate in STEP 2). Weigh, as the morning card does:
SP matchup (35%: xERA or ERA with K% and BB%, handedness, last three starts),
bullpen (15%: relief IP over the last 3 days, arms on back-to-back days or
25+ pitches yesterday), offense against this SP's hand (20%: OPS, K%,
tonight's actual lineup and absences), park and first-pitch weather (10%;
rain above 40% = skip), umpire (5%, context only), team quality (15%),
line movement since the morning bundle, schedule spot (5%).
One WebSearch "<team> lineup injury news today" for the strongest candidate
if anything is unclear.

  p_model    = your win probability for the side
  break_even = |best price| / (|best price| + 100)      (vig included)
  edge       = (p_model - break_even) x 100 points
A-tier (4.0+) only. Favorites only. 1u, or 0.5u at -200 or shorter.
SANITY CHECK: if p_model is more than 8 points from the game sheet's no-vig
fair probability, re-check the inputs; it is almost always a data error. If
the inputs hold, the edge counts as 4.0 at most.
Skip: SP unconfirmed or opener, lineup not posted, rain above 40%, line moved
15+ cents against the side since the morning bundle, price not real.

STEP 6 - STRIKEOUT PROPS (OPEN games only; 0-3 web calls)

Candidates: confirmed traditional starters (no openers or bulk relievers)
whose season line shows in the game sheet. Inputs, from the game sheet:
- sp_k_pct: the SP's season K% as a fraction (27.9 -> 0.279)

python3 - <<'PY'
import json, math
CALIBRATION = 0.82
LEAGUE_K_PCT = 0.225   # replace with the PA-weighted league K% if the bundle's team splits give it

def p_over(line, mu):
    k, cdf, term = int(line), 0.0, math.exp(-mu)
    for i in range(k + 1):
        cdf += term
        term *= mu / (i + 1)
    return max(0.0, min(1.0, 1.0 - cdf))
def imp(o): return abs(o) / (abs(o) + 100) if o < 0 else 100 / (o + 100)
def tier(e): return 'A' if e >= 4 else 'B' if e >= 2.5 else 'C' if e >= 1 else 'Pass'

CANDIDATES = [
    # {'name': 'Tarik Skubal', 'line': 7.5, 'over': -120, 'under': -105, 'book': 'fanduel',
    #  'sp_k_pct': 0.31, 'opp_k_pct': 0.24, 'projected_ip': 6.2, 'umpire_k_adj': 0.0},
]
for c in CANDIDATES:
    k_rate = max(0.05, min(0.50, c['sp_k_pct'] * c['opp_k_pct'] / LEAGUE_K_PCT + c['umpire_k_adj']))
    mu = k_rate * c['projected_ip'] * 4.3          # ~4.3 batters faced per inning
    po = 0.5 + CALIBRATION * (p_over(c['line'], mu) - 0.5)
    e_over, e_under = 100 * (po - imp(c['over'])), 100 * ((1 - po) - imp(c['under']))
    print(json.dumps({'name': c['name'], 'line': c['line'], 'mean_k': round(mu, 2), 'p_over': round(po, 3),
                      'edge_over': round(e_over, 1), 'tier_over': tier(e_over),
                      'edge_under': round(e_under, 1), 'tier_under': tier(e_under)}))
