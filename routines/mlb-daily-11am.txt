STEP 9 - ANALYZE each game using these 8 layers:

LAYER 1 - SP MATCHUP (35% weight):
- xERA differential between the two SPs (key signal)
- K% and BB% (command), whiff% (swing-and-miss arsenal)
- Handedness vs lineup composition (platoon advantage)
- Recent 3-start trend: any velocity decline, elevated walk rate?
- Projected IP: traditional starter (6-7 inn), bullpen game (flag explicitly)

LAYER 2 - BULLPEN (15% weight):
- Any pen overuse in last 3 days (>6 IP = fatigued)
- Closer/setup man used 3 consecutive days = unavailable, flag for late-game ML
- If bullpen game: use team pen xERA as the "starter" equivalent

LAYER 3 - OFFENSE VS PITCHER (20% weight):
- OPS vs SP handedness (>0.750 = strong, <0.680 = weak)
- Platoon advantage: note if lineup stacks same hand as SP (disadvantage) or opposite (advantage)
- Recent form: last 7-14 game offensive trend

LAYER 4 - PARK + WEATHER (10% weight):
- Known hitter parks: Coors (+), Great American (+), Yankee Stadium (+LHB)
- Pitcher parks: Petco (-), Oracle (-), Tropicana (dome, neutral)
- Apply wind and temp adjustments from Step 7

LAYER 5 - UMPIRE (5% weight):
- K-friendly ump: -0.3 total lean, suppresses run scoring
- Run-friendly ump: +0.3 total lean
- Use as secondary signal only, cap adjustment at ±0.5 runs

LAYER 6 - PYTHAGOREAN BASELINE (15% weight):
- Better team by actual record? Pythagorean record (RS/RA based) more predictive than W/L
- Teams with Pythagorean > actual W% are "unlucky" and likely to improve
- Use as baseline team quality signal, then SP/context layers adjust

LAYER 7 - LINE MOVEMENT (signal check):
- Line moving toward your pick = smart money agrees (positive signal)
- Line moving against your pick = concern, reduce confidence, consider skip

LAYER 8 - SCHEDULE SPOT (5% weight):
- Back-to-back game, getaway day, cross-country travel: slight negative
- Well-rested team vs fatigued opponent: slight positive

MARKET HIERARCHY:
- ML is the only proven market. Lead every card here. Target 2-4 ML plays.
- Totals: only play if park + weather + umpire ALL point same direction AND edge is A-tier (>=4%). Cap 0.5u.
- Run lines: do not play. 0-3 tracked record. Skip.

EDGE TIERS:
- A = model win prob beats implied prob by 4%+
- B = 2.5-3.9% gap
- C = 1.0-2.4% gap
- Pass = under 1%

CONFIDENCE TO UNITS:
- 8-10 (A-tier edge, all layers aligned, confirmed SP) = 2u HIGH CONFIDENCE
- 7 (B-tier edge, most layers aligned) = 1u VALUE PLAY
- 6 (C-tier, plus-money only) = 0.5u LEAN

Units won calculation: negative odds e.g. -130: win = bet * (100/130). Positive e.g. +140: win = bet * (140/100). Round to 2dp.
