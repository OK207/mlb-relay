===================================================
STEP 6 - ANALYSIS (0-2 web calls for targeted deep research)
===================================================

For each main card fight, run this framework:

FACTOR BLEND WEIGHTS:
- 30% Fighter statistical profile (SLpM diff, striking defense, TD%, KD ratio, submission rate)
- 25% Style matchup advantage (striker vs grappler interaction, wrestling vs sub defense)
- 20% Recent form + opponent quality (last 3 fights trajectory: Dominant/Competitive/Survival/Loss)
- 15% Physical attributes (reach, age, experience, avg fight time)
- 10% Context factors (weight cut severity, layoff, home crowd, late replacement)

STRIKER vs GRAPPLER SCORING:
- Classify each fighter: Striker / Grappler / Wrestler / Mixed
- Striker vs Grappler: who closes the distance? Striker advantage if good footwork/distance; Grappler advantage if high TD accuracy vs low sprawl
- Wrestler vs BJJ: wrestler controls position; BJJ specialist submits from bottom
- Striking differential (SDS = SLpM - SApM): gap > 2.0 = strong signal for the positive side

CONFIDENCE SCORING (clamp 1-10):
Base: 5
+2 if style matchup strongly favors pick and stats confirm
+1 if multiple independent metrics agree (SLpM diff, TD%, finishing method)
+1 if market line has NOT moved against pick
+1 if physical attributes AND recency both support pick
+1 if fighter has strong KO power vs opponent with documented chin concerns
-1 for method-of-victory or round prop (higher variance)
-2 if either fighter is late replacement or > 12 months layoff
-1 if statistical model disagrees with recent form trajectory
-1 if weight cut concern flagged

WIN PROBABILITY MODEL (simplified):
1. Base win prob from ML market (convert to vig-free): if -200, implied = 200/300 = 66.7%
2. Adjust from stats: SLpM differential, style advantage, form trajectory
3. Model win prob = market implied + adjustments (cap adjustment at +/-15%)
4. Edge = model win prob - market implied break-even
5. Tiers: A >= 4% | B 2.5-3.9% | C 1-2.4% | Pass < 1%

MARKET HIERARCHY:
- ML is primary. Target 3-5 ML plays. Underdogs often +EV (public overbacks favorites).
- Method of Victory: only if A-tier edge, clear finishing path, KO rate > 40% or sub rate > 30%
- Round O/U: only A-tier, all factors aligned (finish rates, style, avg fight time)
- Do not pad with low-quality plays to hit volume.

STAKING RULES:
- ML: cap 1.0u standard. Heavy favorite (-300+): cap 0.5u.
- Method prop: cap 0.5u max.
- Round O/U: cap 0.5u, A-tier only.
- Late replacement: cap 0.5u regardless of edge.

SKIP conditions:
- Edge < 1% after full analysis
- Fighter unconfirmed or very late replacement (< 3 days)
- Model and form trajectory strongly disagree with no explanation
